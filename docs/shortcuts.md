# Search and shortcuts

Find anything fast and drive Vendi from the keyboard.

On the site: https://ttfunnel.ai/docs/shortcuts

## Search

Press Cmd+K (Ctrl+K on Windows) anywhere to jump to a page, setting, app, agent, message or CRM record, or to start a new record. Type a full sentence and **Ask Vendi** sends it to Vendi.

## Keyboard shortcuts

On Windows, use Ctrl instead of Cmd.

| Keys | Does |
| --- | --- |
| Cmd+K | Search |
| Cmd+B | Show or hide the sidebar |
| Cmd+Shift+F | Focus on the chat |
| Cmd+1 to Cmd+9 | Open an agent |
| Cmd+F | Search this conversation |
| Cmd+⏎ | While an agent answers: add to the answer now instead of sending after it (or the other way round, by your setting). With task windows on: send as a task |
| Cmd+Shift+⏎ | With task windows on, while Vendi answers: add to the answer now instead of sending after it |
| Cmd+' | Quote the selected part of an answer |
| 1 to 9 | Pick an answer to an agent's question |
| ↑ / ↓ | In an empty message box: your earlier messages |
| Cmd+Shift+V | Paste a long text as text instead of a file |

## Commands

Type `/` in the message box, or send these in a [chat app](chat-apps.md). In Slack, start with `/vendi`.

| Command | Does |
| --- | --- |
| `/new` | In a chat app, starts a new conversation |
| `/stop` | Stops the answer being written |
| `/automations` | Lists your automations, with Run now and Pause |
| `/competitors` | Watches your competitors. See [Competitor watch](competitor-watch.md) |
| `/apps` | Shows connected apps and links to connect more |
| `/changes` | Shows changes waiting for your approval |
| `/timezone` | Shows or sets your time zone |
| `/usage` | Shows the questions your team has left this month |
| `/voice on` or `/voice off` | Turns voice notes in chat apps on or off |
| `/help` | Shows every command with an example |
| `/report` or `/bug` | Sends feedback to the TTFunnel team |
