# Free and Pro

What each plan includes.

On the site: https://ttfunnel.ai/docs/plans

Everyone in a team shares one plan. **Settings › Plan and Usage** shows yours and how many questions your team has left this month.

| | Free | Pro |
| --- | --- | --- |
| Questions each month | A starter allowance | A much larger allowance |
| Notetakers | One | All of them |
| CRM, workspace and lead apps | No | Yes |
| Answer modes | Fast | Fast and Smart |
| Automations | One | Many |
| Chat apps | Yes | Yes, with voice notes |
| Voice chats | No | Yes |
| Leads | No | Yes |
| Competitor watch | No | Yes |
| Claude and ChatGPT | No | Yes |
| Notion backups | No | Yes |
| Your own apps and websites | No | Yes |
| CRM | Yes | Yes |

Note: Pro is coming soon. Features that need it are marked (Pro) in these docs.
